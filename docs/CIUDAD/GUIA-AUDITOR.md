## 🜄 Comandos del Auditor

```bash
# Verificar un hash
auditor verify --hash=f03f7e2d...

# Auditar cadena completa
auditor chain --from=genesis --to=current

# Reportar anomalía
auditor report --hash=f03f7e2d... --razon="...firma inválida"

# Emitir acta de auditoría
auditor sign-acta --period=2026-Q1
```

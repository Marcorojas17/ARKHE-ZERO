⛓️ Anclaje Ethereum

🜂 Qué hace

Convierte un Merkle root en una transacción data-only a Ethereum mainnet. El root queda anclado permanentemente.

🜃 Uso

import { anclar } from './anchor.js';

const doc = 'Acta fundacional ARKHÉ ZERO · 2026';
const hash = sha3_512(doc);
const ancla = await anclar({ hash, red: 'mainnet' });

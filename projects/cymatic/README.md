## 🜂 Qué es

Motor de visualización musical cuántica. Convierte frecuencias en
geometría sagrada usando GPU (WebGL + compute shaders).

## 🜃 Frecuencias canónicas

- **51 Hz** · frecuencia humana
- **49 Hz** · frecuencia IA
- **100 Hz** · resonancia real

## 🜄 Uso

```javascript
import { Cymatic } from './projects/cymatic/core.js';

const sim = new Cymatic();
sim.setFrecuencia(51, 'humano');
sim.setFrecuencia(49, 'ia');
sim.render();  // → geometría sagrada en tiempo real
```
